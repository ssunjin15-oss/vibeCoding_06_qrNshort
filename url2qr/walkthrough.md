# 워크스루: URL2QR (프로젝트04)

## 사용 방법
1. 사이트에 접속하면 상단 좌측에 로고, 가운데에 URL 입력창이 보입니다.
2. URL을 입력하고 **확인**을 누릅니다. `https://`는 생략해도 됩니다.
3. 입력창이 아래로 내려가고 화면 정중앙에 QR코드가 나타납니다.
4. QR코드를 클릭하면 `qrcode_날짜시각.jpg` 파일로 저장됩니다.
5. 마우스를 움직이면 배경 그라데이션의 위치와 색이 조금씩 바뀝니다.

## 확인한 결과
| 항목 | 결과 |
|---|---|
| 로고 표시 | 정상 |
| 잘못된 URL 입력 시 안내 | "올바른 URL을 입력해 주세요" 표시 |
| QR 생성과 레이아웃 전환 | 정상 |
| JPG 다운로드 | 정상, 판독 결과가 입력한 URL과 일치 |
| 모바일 화면 | 정상 |

## 연결
- 이 결과물은 프로젝트06(QRnShort)의 `url2qr` 폴더로 그대로 복사되어 'QR코드' 기능으로 사용됩니다.
